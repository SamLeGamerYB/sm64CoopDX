# sm64coopdx Mod launcher

![Static Badge](https://img.shields.io/badge/Build_with-Visual_Studio_Code-blue)

> This is a beta project, so there will be lots of bugs. if you encounter any bugs please [click here](https://github.com/SamLeGamerYB/sm64CoopDX/issues/new?labels=Bug) to report the bug :D

**This application is a mod launcher for [Super Mario 64 Co-op Deluxe](https://sm64coopdx.com/)**

This is a project that i always wanted to make since i saw this SM64 modloader and multiplayer. Because it looks so fun. 
But sadly if you want to know if there is an update to any mod you must turn on notifications and check on the website then delete the old file, replace...

It's *boring* what about having a mod loader with...
- Modpacks
- Mod Updater
- Download dependencies automatically
- 80% customisable
- Launch the game from the launcher
- Auto update the launcher and sm64coopdx when available

**And more...**  

Taking the mods from `https://mods.sm64coopdx.com/`  
This app is 100% FREE and AD-FREE

## F.A.Q.
